# TestAi

## 猿来编码 - 登录界面

这是一个现代化的登录界面，具有以下特色：

### 🎨 设计特点
- **暖色调渐变背景** - 采用橙色到金色的温暖渐变色彩
- **品牌标识** - "猿来编码"品牌名称配合编程图标
- **现代化UI** - 玻璃拟态设计，阴影效果和悬浮动画
- **响应式设计** - 完美适配桌面和移动设备

### 🚀 功能特性
- 用户名/邮箱登录
- 密码输入
- 记住我选项
- 社交登录（GitHub、Google）
- 输入验证和动画反馈
- 加载状态指示

### 📱 查看界面
打开 `index.html` 即可查看登录界面。

### 🛠 技术栈
- HTML5
- CSS3 (渐变、动画、响应式)
- JavaScript (ES6+)
- Font Awesome 图标库
